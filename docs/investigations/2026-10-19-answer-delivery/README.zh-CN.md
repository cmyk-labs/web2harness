# 正文交付调查归档 — 2026-10-19

[English](README.md) | [简体中文](README.zh-CN.md) · [项目文档](../../../README.zh-CN.md#documentation)

本归档以前后两轮直接Chrome网页观察、正文提取与校验分析为主体；两次正式版故障、两个真实DEV任务及后续修复记录作为背景证据。**结论：应在确认当前逻辑回答完成后读取完整内容；仅等待文字不变，或在完成后读取一次可见DOM，都不足以保证正确交付。**

这是截至2026-10-19（Asia/Shanghai）的调查记录，不是现行操作说明、发布验收或全部Codex能力兼容声明。网页观察后的新设计建议尚未实施。此次归档仅改文档，没有运行新的模型任务、修改产品源码、提交或发布。

## 结论与证据对应

证据强度分为：**现场观察**、**源码/纯函数确认**、**风险推断**、**未验证**。一次网页成功不能替代Web2Harness端到端验收；夹具通过不能抹去真实失败。

| 编号 | 结论 | 证据及适用范围 |
| --- | --- | --- |
| C01 | 正文不变不代表回答完成 | [E05](evidence.zh-CN.md#e05)：生成期间正文连续242.303秒不变，Stop仍存在，后续工具/网络仍进行。现场观察，不能据此规定固定静止时长。 |
| C02 | 页面停止运行不一定是成功完成 | [E06、E07](evidence.zh-CN.md#e07)：主动停止300项列表时仅到第20项，复制/重新生成已出现；源无成功终态。现有纯函数将该DOM状态判为完成，且不完整传输允许DOM回退。判据缺口已确认，完整项目误交付尚未复现。 |
| C03 | 完成后DOM仍可能只是完整内容的一部分 | [E06](evidence.zh-CN.md#e06)：120行代码完成后，仅打开菜单引发页面位置变化，DOM可读赋值降至57行，末尾正文标记仍在；完整公开代码源未变。代码组件虚拟化已观察。 |
| C04 | 外层容器、正文根、消息版本和网络请求不是同一个身份 | [E05、E06](evidence.zh-CN.md#e06)：外层包含问题、进度和正文；commentary也有消息ID；重新生成同一问题会更换回答版本，编辑会形成新分支。不能只按外层turn或任意消息ID取final。 |
| C05 | 网络错误、工具错误和整轮失败需分别判断 | [E05、E06](evidence.zh-CN.md#e06)：自然断线后自动续接完成；本轮五次正常完成和一次主动停止均以ERR_ABORTED结束；Python除零后第二次执行成功，整轮完成。网络根因未定位，不能直接归因给项目或本机。 |
| C06 | 当前公开响应协议与富内容适配不完整 | [E05、E06、E08](evidence.zh-CN.md#e08)：现场有上下文切换、合并消息、结构化引用、虚拟代码、图表、图片和文件预览；当前解析与DOM转换未完整覆盖这些表示。源码与现场结构对应，不等于全部媒体端到端已复现失败。 |
| C07 | 未交付草稿的历史前缀约束有误拒风险 | [E01、E04、E08](evidence.zh-CN.md#e08)：历史合成表格增长及真实表格包装变化曾触发误拒并已针对性修复；当前buffered完整重建仍要求保留全部已知前缀。建议改由完整最终内容证明正确，尚未用本轮样本端到端验证新策略。 |
| C08 | 剪贴板、DOM与原响应不应三方逐字互证 | [E05](evidence.zh-CN.md#e05)：整段复制混入Mermaid CSS并缺语言/图源码；原响应含私用标记需解析引用。长度不同本身不是缺段证明，也不存在可无条件透传的万能来源。 |
| C09 | 原生等待不占Web执行名额是已有行为 | [E03](evidence.zh-CN.md#e03)：父agent等待时三个子请求在执行，父agent无活动Web请求。不能将其当作本次新增能力或失败原因。 |
| C10 | 独立超时已优化，历史问题仍需分别闭合 | [E04](evidence.zh-CN.md#e04)：附件预算算出1ms是已确认的项目回归；跨步骤总额度已取消并通过相关自动化检查。新候选真实任务验收被用户暂缓，未知发送、队列身份冲突及完整正文真实结果不能据此宣布解决。 |

## 现有实现与建议

现有实现已经有响应源优先、完成后整段交付、DOM独立回退、运行/工具状态检查、Codex取消分支以及完成后网络关闭容忍。不能将其概括为“只看文本稳定”，也不需要另建一套平行执行框架。源码身份及关键片段固定在[E08](evidence.zh-CN.md#e08)。

建议在现有职责内依次调整，**以下均为待实施建议**：

1. **先确认逻辑完成。** 关联发送、用户turn、当前回答版本和续接请求。依据绑定正确的公开最终终态完成交付；DOM回退需要当前回答的正向完成证据。复制按钮、静止时间仅作辅助。取消、失败与可恢复中断不能变成成功，也不能因为最后一个网络错误而否定已完成回答。
2. **再读取完整内容并分类转换。** 补齐公开合并响应、上下文与引用。普通文本可回退DOM；虚拟代码、图表、公式、Mermaid、图片和文件读取对应完整语义数据。不能执行网页提供的渲染程序、混入隐藏思考或把网页sandbox路径当成本机文件。未知类型明确披露限制，不能静默删除。
3. **减少无效防御。** 未向下游交付的草稿允许修改、重排、节点合并与拆分；最终完整内容负责正确性。已外发增量仍保留不可撤回约束。身份、模型/档位、权限、真实终态和工具协议检查保持；不要求多个表示逐字相等，不把样式或视口变化当正文损坏。
4. **按影响定向验收。** 验证取消不误报成功、已完成断流不误报失败、续接不重发、代码不缺行、分支不串回答、缓冲与增量约束分别成立，再做受影响的独立DEV真实验收。保持已经批准的独立操作超时，不重新引入跨步骤总额度。

目标仍是让网页模型承担模型交互，保留Codex原生工具、执行、权限、沙箱、等待和已支持的流式能力。不能通过禁用工具、媒体或流式来宣称等价；本报告也没有证明所有Codex能力已兼容。

## 未闭合问题

- 两次历史正式版事件缺少完整原始流和相邻DOM，无法精确重放；未知发送的底层原因、后续queue_identity_conflict仍未闭合。
- 本轮没有通过Web2Harness执行这些网页样本，取消判据测试不是完整误交付复现。新策略尚未实现和验收。
- CSV预览已看到，下载事件未捕获，本地文件落盘未验证；未覆盖完整音视频、其他模型或长历史整体虚拟化。
- 没有观测到同一回答任意段落合并/拆分或根节点重挂载；实际确认的是代码组件虚拟化及重新生成换版本。两者不能混写。
- 原生密文迁移、其他托管工具、媒体和WebSocket能力应继续依照[兼容范围](../../native-tools-compatibility.zh-CN.md)逐项验收，不能用这次正文调查关闭全部兼容缺口。

证据包保存脱敏结论、既有验证摘要、源码片段、原记录路径及SHA-256。**哈希只能核对材料身份，不能补回缺失的原始流，也不能自行证明结论正确。**原始私有日志、认证、浏览器状态和生产基线不进入此归档。详见[证据索引](evidence.zh-CN.md)。
